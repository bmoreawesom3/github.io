The ribbon in Revit

The CNCPT tab as it appears on the Revit ribbon, grouped into panels by purpose.

Everything lives under a single CNCPT ribbon tab, organized into panels so the right tool is never more than a click or a pulldown away. Tools range from one-off links to standards and reference material, to full Dynamo- and C#-driven automation that touches sheets, views, rooms, spaces, and discipline-specific modeling tasks. In total the tab holds 70 tools: 22 in Resources, 22 in Utilities, 23 across the Disciplines panel, and 3 in BIM Management.

Resources panel

  • Model Metrics — Opens the Model Metrics Dashboard hosted on BIMBeats.
  • Project Creator — Copies a folder tree, renames RVTs (keeps the A01-style suffix), saves a new host, and relinks Revit links.
  • Links pulldown — Cube, YouCube, the Revit Cubed playlist, Pinnacle, and the Autodesk website.
  • Policies pulldown — BIM Job Captain responsibilities, the Clash Detection procedure, Revit Project Setup, and the Upgrading Projects policy.
  • Requests pulldown — ACC License requests, Clarity setup, Family Creation (routed through Outlook), and Clash Detection setup requests.
  • BIM Standards pulldown — Clark Nexsen BIM Standards, NCS, Navfac, AEC, Veterans Affairs, BCOM, and SCO standards.

Utilities panel

  • Clash Resolver — Imports a Navisworks XML clash report, reviews clash statuses, selects clashing elements in Revit, and exports the updated report.
  • General pulldown — Export sheets impacted by revisions, create revision print sets, center all rooms/spaces/areas, rotate elements 90° about their own center, plus Dynamo scripts to generate views from a seed and delete views by phase.
  • Sheet pulldown — Renumber viewports by titleblock grid or by position, bulk sheet creation, update sheet approve/design/review parameters, and show or hide crop regions across selected sheets.
  • View pulldown — Make grid lines 2D in the current view; flip selected grid ends.
  • Space pulldown — Center space tags, set the MEP space limit offset to 20', and delete unoccupied/redundant or all spaces.
  • Room pulldown — Center room tags in view; delete rooms that aren't placed.

Disciplines panel

  • Architectural — A reference-links panel with live-thumbnail cards for codes and standards, an off-angle wall/grid finder, occupancy code schedule import from Excel, and door renumbering by room.
  • Mechanical — Sizing guidelines, space-data export/import against Excel, air terminal placement and alignment to the ceiling grid, terminal and duct/pipe tagging, building-envelope HVAC takeoffs, duct/pipe modeling from equipment, duct length calculation, and insulation application by system type.
  • Electrical — Voltage drop and feeder length calculation up the supply-from chain, MEP space limit offset via ray-casting to the ceiling or structure above, and lighting device alignment to the ceiling grid.
  • Plumbing — Models piping connections directly from selected equipment.
  • Fire Protection & Structural — Reserved "Future Tool" placeholders, not yet implemented.

BIM Management panel

Conditional — only visible to users on a whitelist checked at runtime.

  • Revit File Report — Generates a detailed XML report per RVT file covering worksets, line styles/patterns, families & types, levels, grids, phases, scope boxes, materials, and fill patterns.
  • Report Dashboard — Loads generated reports in the browser to visualize and compare worksets, families, line styles, sheets, and materials across up to 8 files side by side.
  • Gemini — Opens the AI Toolbox with Gemini login/access instructions.
