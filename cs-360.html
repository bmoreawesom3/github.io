CS-360: Mobile App Development

A native Android weight-tracking app built in Java — user login backed by a local SQLite database, a dashboard for logging and reviewing weight entries, and goal notifications.

This is a native Android application for tracking weight-loss progress. It stores accounts and entries locally using a SQLite database, accessed through a data-access layer so the UI stays separate from the storage logic. The app is organized around a login screen and a set of fragment screens for the home view, a dashboard, weight entry, and notifications.

What I built

  • A login screen backed by a SQLite database for user accounts.
  • A data-access layer (DAO) and a User model separating storage from the UI.
  • A dashboard and weight-entry screen for logging and reviewing progress.
  • A notifications screen for goal-related alerts.
  • A fragment-based architecture following Android conventions.
