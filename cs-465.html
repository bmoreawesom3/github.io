Travlr Getaways is a travel-booking site built on the MEAN stack. It's organized into three tiers: a customer-facing web app served by Express with Handlebars templating (app_server), a REST API backed by MongoDB and Mongoose models (app_api), and a single-page Angular admin application for staff to manage trips (app_admin).

Built across modules

The repository is organized by module: branches module1 through module7 each capture a stage of the build, so the history of the application is visible branch by branch. module7 is the finished version, adding JWT authentication with Passport to secure the administrative routes. The main branch is intentionally minimal — the working code lives on the module branches.

What I worked on

  • Built the customer-facing site with Express and Handlebars server-side templating.
  • Designed a REST API with Express and MongoDB/Mongoose models for trips and users.
  • Created an Angular single-page admin panel to add, edit, and list trips.
  • Added JWT-based authentication with Passport to protect administrative routes.
  • Structured the work across seven module branches, ending with a complete application.
